# MOTCHI LIFE

색이 들어간 작은 도트 캐릭터를 중심으로 즐기는 모바일 육성 게임입니다. 캐릭터 주변의 밥·씻기·청소·대화·휴식·치료 버튼, 아래쪽의 주요 활동 메뉴를 바로 누를 수 있습니다. 기존 MOTCHI 저장 데이터가 있으면 기본 나이와 상태를 가져오고, 이후 진행은 브라우저에 자동 저장됩니다.

## 플레이

- 처음에는 다섯 색의 모찌와 세 가지 집 중 하나를 고릅니다. 알은 빠르게 터치해 게이지를 0으로 만들거나 실제 시간 약 5분 뒤 부화합니다. 아이 → 청소년 → 성체 → 노년으로 성장하며 돌봄에 따라 다섯 가지 성체 모습이 나옵니다.
- 낮에는 1~2시간 간격으로 식사·휴식·대화 등 짧게 돌보도록 설계했습니다. 오래 방치하거나 질병을 치료하지 않으면 건강이 악화되고 죽을 수 있습니다. 밤과 돌봄교실에서는 상태 변화가 완화됩니다.
- 학교 6과목, 직접 조작하는 미니게임 5종, 운동 5종, 위생 행동 5종, 슈퍼마켓, 직업 5종, 결혼·자녀·다음 세대·추억 앨범을 포함합니다.
- 미니게임은 작은 선택 팝업 대신 화면 전체가 게임 장소로 바뀝니다. 벽돌깨기는 바를 좌우로 드래그하고, 줄넘기는 캐릭터를 터치해 점프시키며, 공 받기·기억력·퀴즈도 각각 화면을 직접 조작합니다.
- 학교는 답 카드를 끌어 놓고, 씻기는 화면을 문지르며, 운동은 걷기·스트레칭·줄넘기·공놀이·수영을 각각 다른 손동작으로 플레이합니다. 활동 화면의 왼쪽 위 화살표로 언제든 중단할 수 있습니다.
- 미니게임은 설명 카드와 3·2·1 카운트다운 뒤 30초 플레이합니다. 시작 번개는 30개이고 게임·도전에 한 개씩 사용합니다. 5분마다 한 개 충전되며 상점에서 수량을 골라 살 수도 있습니다.
- **도전**은 집 화면의 별도 버튼으로 시작합니다. 10단계 × 5웨이브, 웨이브마다 보이는 몬스터 25마리를 모찌가 빠른 연타로 자동 공격합니다. 실패나 중단 시 현재 단계의 첫 웨이브부터 다시 시작하며 모찌가 사망하지는 않습니다. 아령·줄넘기·책 무기는 구매 후 장착하고 최대 Lv.5까지 업그레이드할 수 있습니다.
- 공 받기 등 놀이로 회피·체력·지능을 키우면 전투에 반영됩니다. 돌봄 중 간혹 할아버지와 점수 대결을 하고, 승리하면 보석을 얻습니다. 보석은 현금 구매가 아닌 게임 내 보상입니다.
- 상점에서 꽃·조명·넓은 방을 구매할 수 있습니다. 장시간 자리를 비운 뒤 돌아오면 직업 등에 따른 코인과 작은 집 변화가 기록됩니다.

## 배포

이 폴더의 파일과 `.github/workflows/pages.yml`을 `motchi-tamagotchi` 저장소 최상위에 올리면 됩니다. GitHub 저장소의 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 선택하세요. `Deploy MOTCHI LIFE` 작업이 성공하면 `https://cmw102888.github.io/motchi-tamagotchi/`에서 열립니다.

PWA 설치와 오프라인 캐시는 HTTPS 또는 localhost에서만 작동합니다. 아이폰은 Safari 공유 메뉴의 **홈 화면에 추가**를 사용하세요. 진행 상황은 해당 기기의 브라우저 저장소에만 보관되므로 브라우저 데이터를 지우거나 다른 기기로 옮기면 자동으로 이어지지 않습니다.

도트 그림은 제공된 참고 사진의 작은 픽셀 감각을 바탕으로 새로 그렸습니다. 화면 배치는 모바일 게임의 상단 상태 표시, 좌우 빠른 행동 버튼, 하단 활동 메뉴를 참고했으며 원본 제품 화면을 그대로 복제하지 않았습니다.
